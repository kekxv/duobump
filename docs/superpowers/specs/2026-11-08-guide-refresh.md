# 孕期指南第二版

目标：美化现有静态站，提供可行动的产检与准备说明、独立参考网址页和真正的 hash 路由。

- 保留 Astro 静态内容和本机隐私，使用 `BASE_PATH/#/…` 访问页面；不依赖服务器 rewrite 或 History API。
- Hash 导航使用静态入口加载预渲染页面。跨页重新载入入口以隔离页面脚本、事件及清单状态；浏览器前后退、刷新、页内目录均可用。无 JS 仍保留静态页面阅读路径。
- 新增 `/appointments/`，按阶段列出检查目的、筛查与诊断区别、检查前准备和问题清单，显示来源；数值窗口仅标明来源适用地区，不伪装国内统一医嘱。
- 新增 `/references/`，显示全部现有与新增实际核查的官方原文网址、中文用途、机构和地区。
- 强化首页行动入口、版面层次、时间轴、可访问焦点和手机布局。现有计算器、食物筛选、待产包及中文搜索保持可用。
- 开发和根路径/仓库子路径构建都能使用；不进行公开发布。
