# 分阶段身体变化与首页插画优化

**目标：** 让读者按孕期阶段了解常见的身体和情绪变化、可尝试的照护方式与需要就医的信号，优化首页既有插画。

**需求：** 用户希望“大大小小的状况都加上，让用户心里有数”，并美化首页图片。

**实现：** 新增来源关联的症状数据和可搜索、按身体部位筛选的阶段说明组件；放在现有早中晚期详情页中，并从时间轴提供直达入口。急症提示常驻，不被搜索过滤。现有原文指南、Hash路由、排版及风险数据保持。插画在既有SVG资产中改进。

## 约束
- 广泛覆盖常见状况，不声称列尽所有疾病；不把常见等同于安全。
- 每条说明包含表现、原因说明、日常照护、联系医生的时机、来源和待专业审核状态。
- 不补造概率、不提供药物处方；红旗沿用现有异常信号数据的就医要求。
- 阶段只提示常见出现时机，跨阶段症状共用资料；不能凭孕周排除问题。
- 新增科普继续受专业审核发布门禁约束。
- 在现有非Git项目内修改，不初始化仓库、不提交、不部署。
